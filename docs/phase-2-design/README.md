# Phase 2: UI/UX (Concept 06)

Phase 2 builds on the approved Phase 1 architecture in [../website-architecture/](../website-architecture/). It adapts the design to the approved content and never rewrites content to fit the design.

| C. Design approval | ☐ **Awaiting your approval** |
